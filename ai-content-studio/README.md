# ai-content-studio — AI 內容工作室（副業專案）

> `ai-work` 底下的新專案。目標：用「多 AI 角色分工的產線」，產出**高質感**的 AI 生成內容（先小說／旁白影片，後漫畫），放到可變現平台（YouTube 起步）。
>
> **差異化定位**：解決市面 AI 內容的三大痛點 —— 角色不定型、劇情有漏洞、質感前後不一。

## 產線設計（規劃中）
先想成「**階段**」，之後流程穩定再各自升級成獨立 sub agent；作品「流過」階段，階段跨作品重複使用：

```
發想 → 編劇（＋共創 / 校稿）→ 角色設定 → 分鏡/繪圖 → 審查 → 組裝 → 發布
```

- **共創**：編劇的發想搭檔（丟點子、擴寫、想分支），對治「靈感枯竭」。
- **校稿**：常識與設定的守門員（抓邏輯洞、抓前後矛盾），對治「偏離常識」。
- 管理層（總編輯／秘書／財務／後端…）等有多條產線時再加，不在初期。

## 原則
最小模組起步、產出視為草稿待審；設定一律以 `STORY_BIBLE.md` 為準。
